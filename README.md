# metu_ezekiel_chiebube_engineering_unit_converter
A Python program that converts engineering measurements between different units


What it does

The Engineering Unit Converter is a Python program designed to convert different engineering measurements from one unit to another.

How to run it

1. Install Python 3.
2. Download the project from this repository.
3. Open the Python file in a Python editor.
4. Run the program using:

python engineering_unit_converter.py

Sample output

===== ENGINEERING UNIT CONVERTER =====
Enter unit: mm
Enter the value: 100
100.0 mm = 3.937 inches
Do you want to convert again? (yes/no): yes
===== ENGINEERING UNIT CONVERTER =====
Enter unit: °C
Enter the value: 25
25.0 °C = 77.0 °F

My own twist

My additional feature is automatic reverse conversion.
